# Security Policy

## Reporting a Vulnerability

We take the security of Shield.js seriously. If you discover a security vulnerability or exploit bypass, please report it responsibly so we can remediate it before public disclosure.

### Confidential Reporting Channels:
- **Email:** Send details directly to `bhiseabhay890@gmail.com` with the subject `[SECURITY VULNERABILITY] Shield.js`.
- **Feedback Portal:** Submit via the official portal at [https://shield-js.vercel.app/feedback](https://shield-js.vercel.app/feedback) selecting the **Bug Report** category.

Please include:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept (PoC).
3. Affected browsers and operating system environments.

We will acknowledge receipt within 48 hours and work with you on a timely resolution.
