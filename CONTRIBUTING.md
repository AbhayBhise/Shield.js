# Contributing to Shield.js 🛡️

Thank you for your interest in improving Shield.js! We welcome bug reports, security findings, documentation improvements, and thoughtful feature contributions from the community.

## 1. Contributor License Agreement (CLA)
Shield.js is a proprietary, source-available project authored and maintained by **Abhay Bhise**.

To protect the integrity and proprietary ownership of the project while enabling genuine community collaboration, **all contributors must agree to the [Contributor License Agreement (CLA)](./CLA.md)**.

By opening a Pull Request, you acknowledge and agree that your contribution is licensed to Abhay Bhise under the terms of the CLA, ensuring that:
- You grant full, irrevocable commercial and redistribution rights to Abhay Bhise.
- The project remains protected against theft, unauthorized forks, or fragmented ownership.

## 2. Ways to Contribute
- **Bug Reports:** Open an issue on GitHub or submit feedback through our [official feedback portal](https://shield-js.vercel.app/feedback).
- **Security Vulnerabilities:** Please see our [Security Policy](./SECURITY.md) for confidential disclosure instructions.
- **Feature Requests:** Open an Issue with the prefix `[Feature Request]` detailing your use case.
- **Pull Requests:** Please open an issue to discuss significant changes before submitting a PR.

## 3. Code Standards
- Written in clean TypeScript with strict typing.
- Zero external runtime dependencies in `shield-js-core`.
- Maintain minimal bundle footprint (~3KB gzipped).
- Test cross-browser compatibility before submitting.
